Browser History

Before the Browser (1969-1990)

Before web browsers existed, the Internet still existed but it was completely different. Before web browsers, people used FTP, Telnet, Gopher, and Usenet with no way to link documents together.

The First Browser (1990)

Tim Berners-Lee created the first ever web browser at CERN in 1990. It was originally called WorldWideWeb and was then later renamed to Nexus.

Mosaic Web Browser (1993)

The Mosaic web browser was the first widely used web browser that could display images inline with text. It was developed at the National Center for Supercomputing Applications (NCSA) in 1993.

Netscape Navigator (1994)

Netscape Navigator was released in 1994 and quickly became the most popular web browser of its time, and dominated the market with over 80% market share. It introduced many features that are still used in browsers today.

Microsoft Internet Explorer (1995)

Microsoft released Internet Explorer in 1995, based on the Spyglass Mosaic code. Internet Explorer quickly gained market share, eventually surpassing Netscape Navigator.

The Browser Wars (1995-2001)

The Browser Wars were a period of intense competition between Netscape Navigator and Internet Explorer. By 2001, Internet Explorer had over 90% market share.

The Birth of Mozilla (1998)

The Mozilla project began in 1998 with an open-source code to create a new web browser. It led to the development of Firefox.

Firefox (2002-2004)

Firefox went through several name changes at first starting with Phoenix, then to Firebird, then eventually to Firefox. Firefox 1.0 was released in 2004 with key features that included tabs, pop-up blocking, and a customizable interface. This was then known as the end for Internet Explorer.

Safari and Mobile Browsing (2003-2007)

Apple released Safari in 2003, which became the default browser for Mac computers. In 2007, Apple introduced the iPhone, which included a mobile version of Safari. This marked the beginning of mobile web browsing.

Google Chrome (2008)

Google released Chrome in 2008, which quickly gained popularity due to its speed and simplicity. Google Chrome added the V8 JavaScript engine and a multi-process architecture. Chrome now holds about 70% market share.
